# Will Cast — Engineering Portfolio

Personal engineering portfolio showcasing mechanical engineering, hardware development, control systems, and selected projects.

## Website
Once GitHub Pages is enabled, visit https://willcasteng.github.io.

## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then save.

## Customize
- `index.html` contains the complete responsive website, styles, content, and motion.
- To add your portrait, upload `assets/portrait.jpg` to this repository. The homepage will display it automatically.
- Update education, internship descriptions, and project details in `index.html`.
- Do not upload any confidential internship information or images without approval.

The site is a lightweight static page without a build step or external framework.
